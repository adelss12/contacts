# دليل أرقامي

تطبيق عربي خفيف لإدارة جهات الاتصال، يعمل من المتصفح أو كبرنامج Windows، ويحفظ كل شيء داخل جهازك دون إنترنت.

▶️ [فتح برنامج أرقامي](https://adelss12.github.io/contacts/)

## المميزات

- استيراد ملف VCF واحد أو عدة ملفات معًا، أو بسحبها وإفلاتها على الصفحة.
- قراءة صحيحة لملفات أندرويد (الأسماء العربية المرمّزة Quoted-Printable) والأسطر المطوية وملفات Windows-1256 القديمة.
- **دمج** الاستيراد مع الأسماء الموجودة وتجاهل المكرر (يعرف أن 05… و ‎+966… رقم واحد).
- إضافة اسم يدويًا، وتعديله، وحذفه.
- أزرار اتصال وواتساب ونسخ الرقم بجانب كل رقم.
- بحث ذكي: «احمد» يجد «أحمد»، و«فاطمه» يجد «فاطمة»، ويقبل الأرقام العربية ٠٥٥.
- ترتيب أبجدي مع عناوين الحروف.
- زر «تراجع» بعد الحذف أو الاستيراد.
- نسخة احتياطية VCF، وتصدير Excel (CSV) مع الحفاظ على الصفر الأول.
- وضع داكن تلقائي، وتصميم مناسب للجوال.
- يعمل دون إنترنت ويمكن تثبيته على الشاشة الرئيسية (PWA).

## التشغيل

- **المتصفح:** افتح `index.html` باستخدام Live Server.
- **Windows:** `npm install` ثم `npm start`، وللتغليف `npm run package`.

## الخصوصية

تُحفظ جهات الاتصال داخل متصفح المستخدم فقط، ولا تُرفع إلى GitHub أو إلى أي خادم.

## ملفات المشروع

- `index.html` واجهة البرنامج.
- `style.css` التصميم (فاتح/داكن).
- `app.js` الاستيراد والبحث والتعديل والحفظ والتصدير.
- `manifest.webmanifest` و `sw.js` للتثبيت والعمل دون إنترنت.
- `main.js` نافذة برنامج Windows (Electron).
