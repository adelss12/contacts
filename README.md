# دليل أرقامي

تطبيق عربي خفيف لإدارة جهات الاتصال على Windows، ويعمل محليًا دون الحاجة إلى الإنترنت.
## 🌐 تشغيل البرنامج

▶️ [فتح برنامج أرقامي](https://adelss12.github.io/contacts/)

يعمل البرنامج مباشرة من المتصفح، ويمكن استخدامه على الكمبيوتر أو إضافته إلى الشاشة الرئيسية في الآيفون للوصول إليه بسرعة.
## المميزات

- استيراد جهات الاتصال من ملفات VCF.
- دعم أكثر من رقم للاسم الواحد.
- البحث بالاسم أو رقم الهاتف.
- حفظ البيانات محليًا على الجهاز.
- تصدير نسخة احتياطية بصيغة VCF.
- تصدير الأسماء والأرقام إلى ملف CSV يقرأه Excel.
- حذف جميع الأسماء مع رسالة تأكيد توضح العدد.
- واجهة عربية بسيطة ومتجاوبة.

## التشغيل

1. افتح مجلد المشروع في VS Code.
2. افتح ملف `index.html` باستخدام Live Server.
3. اضغط «استيراد VCF» واختر ملف جهات الاتصال.

## الخصوصية

تُحفظ جهات الاتصال داخل متصفح المستخدم فقط، ولا تُرفع إلى GitHub أو إلى أي خادم خارجي.

## ملفات المشروع

- `index.html` لبناء واجهة البرنامج.
- `style.css` لتنسيق وتصميم الواجهة.
- `app.js` للاستيراد والبحث والحفظ والتصدير.
